# Model_Electric — агент папки с показаниями

Небольшой сервис, который запускается **на вашем ПК**: по кнопке «Проверить папку»
в веб-дашборде он сканирует заданную папку, разбирает файлы Excel/CSV с показаниями
и отдаёт данные в дашборд (таблица файлов, итоги, график по каждому показателю).

## Быстрый старт (Windows)

1. Установите Python 3.9+ (галочка «Add to PATH»).
2. Скопируйте `config.example.json` в `config.json` и укажите свою папку в `"folder"`
   (слэши `/` или двойные `\\`).
3. Запустите `start_agent.bat` — откроется дашборд http://127.0.0.1:8765.

Или вручную:

```bash
pip install -r requirements.txt
python agent/folder_agent.py --folder "C:/Data/Показания"
```

## Что умеет

- Файлы: `.csv`, `.txt`, `.xlsx`, `.xlsm` (все листы), включая подпапки.
- CSV: кодировки UTF‑8 и Windows‑1251, разделители `;` `,` табуляция `|`, десятичная запятая.
- Автоматически находит строку заголовков, столбец с датой/временем и числовые столбцы.
- По каждому показателю: последнее значение, прирост (последнее − первое, для накопительных
  счётчиков это расход за период), сумма, среднее, минимум, максимум, график и таблица.
- Отмечает новые, изменённые и удалённые файлы относительно предыдущей проверки.

## API (для своего дашборда)

| Метод | Путь | Что делает |
|---|---|---|
| `POST` | `/api/scan` | команда: проверить папку, вернуть результат |
| `GET` | `/api/result` | результат последней проверки |
| `GET` | `/api/info` | путь к папке, время последней проверки |

## Безопасность

По умолчанию агент слушает только `127.0.0.1` (доступен лишь с этого ПК).
Если открываете доступ по сети (`"host": "0.0.0.0"`), задайте `"token"` — дашборд
попросит его ввести и будет передавать в заголовке `X-Token`. Агент только читает файлы.

`sample_data/` — тестовые файлы для проверки.
