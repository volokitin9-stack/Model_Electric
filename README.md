## Структура папки чертежа

`specs/Wiring_N/`:
- `Wiring_N_source.pdf` — исходная схема;
- `Wiring_N_spec.xlsx` — листы «Чертёж», «Разъёмы», «Распиновка», «BOM», «Замечания», «Источники». В листах «Разъёмы», «Распиновка», «BOM» есть колонки «№ чертежа» и «Автомобиль», чтобы данные разных чертежей можно было сводить в одну таблицу;
- `Wiring_N_spec.md` — то же в markdown.
